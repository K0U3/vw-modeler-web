# 図面からMUJI風パースまで

## 確定した完成形

利用者はWebに平面図をアップロードする。図面の間取り・開口・家具位置を保持した、MUJI家具の実モデルを使うフォトリアルな室内パースをWeb上で生成・保存できる。Vectorworks 2021用スクリプトは追加出力とし、通常の利用にVectorworksの操作を要求しない。

## 基本処理

1. 図面の単位・縮尺・壁・開口・天井高・部屋領域を読み取る。
2. 家具名、詳細な平面形状、寸法、周辺の家具との関係を用いて家具を特定する。
3. 図面座標を保持した共通3Dシーンを生成する。家具は実モデルを原寸で使い、足りないものを箱で埋めない。
4. オーク材、白い壁、淡色の布、金属等の素材、窓からの光、室内灯を設定する。
5. 室内から見たカメラを自動選定し、壁の中や家具と衝突した視点を除外する。
6. 物理ベースのレンダリングを実行し、完成画像と処理状況を表示する。
7. 同じシーンからVectorworks用スクリプトを追加出力する。

情報が足りない図面は、縮尺・天井高・家具候補など必要な項目だけ確認する。曖昧な図面を確定済みと表示しない。既存図面と同じ家具が別名、別位置、別回転で現れても対応できるよう、家具の照合情報は図面とは分離して管理する。

## 実装順序

- 第1段階: DXF入力、共通シーン、MUJI実モデル、Webプレビュー、カメラ1視点、完成PNG。
- 第2段階: 複数視点、素材と照明の調整、家具の確認結果を再利用する仕組み。
- 第3段階: PDF・画像入力の寸法/形状解析、読取結果の重ね合わせ確認。

## 現在の実装と不足

既存WebはDXFからVectorworks用Pythonを返す。Web用メッシュ、素材、照明、カメラ、レンダラー、完成画像の保存は未実装。家具カタログには名称・寸法・VWXシンボル名があるが、ブラウザで使うGLB等のメッシュはない。

家具照合は名前/寸法に加え、確認済み平面記号の形状を図面名・グループ番号に依存せず照合する。単純矩形、競合候補、未検証の反転は保留する。確認済みの元図面には対応表を自動適用するが、これを汎用認識の代わりにしない。

## 共通シーンの設計条件

- 座標: mmの平面XYと高さZを保持し、Web表示時にmへ変換する。
- 部材: 元図面の識別子、輪郭、底面高さ、高さ、素材ID。
- 開口: 対象壁、幅、下端、上端、建具種別。
- 家具: 元記号ID、実モデルID、中心位置、回転、鏡像、元図面寸法、実寸、判定理由。
- モデル台帳: GLBのパス、単位、原点、正面、接地高さ、材料スロット、確認済みの寸法。
- カメラ/照明: シーンと別に保存し、見た目の変更で図面座標を変えない。
- 品質情報: 未確定事項、未配置家具、壁/家具干渉、欠落モデル。欠落があれば完成扱いにしない。

## 完成判定

複数の異なる住戸図面で、アップロードから画像保存までVectorworks操作なしで完了する。家具数・種類・中心・向き・実寸を図面と照合し、レンダリング前後で間取りが変わらない。未登録の家具や不明な尺度を処理失敗/要確認として明示する。B3案だけの成功を全図面対応の証拠にしない。
